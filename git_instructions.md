# Инструкция: Деплой шаблонов и импорт на экзамене через Git (без авторизации)

Данное руководство поможет вам загрузить все шаблоны на GitHub и быстро развернуть их на экзаменационном компьютере через командную строку без необходимости вводить логин и пароль.

---

## ЧАСТЬ 1: Загрузка шаблонов на GitHub (из дома)

### Шаг 1. Создание репозитория на GitHub
1. Перейдите на [github.com](https://github.com) и войдите в свой аккаунт.
2. Нажмите **New** (Создать новый репозиторий).
3. Укажите имя репозитория (например, `exam-templates`).
4. **ВАЖНО:** Выберите тип **Public** (Публичный). Это позволит скачивать проект на экзамене без авторизации.
5. Не ставьте галочки у *Add a README file*, *.gitignore* или *license* (репозиторий должен быть абсолютно пустым).
6. Нажмите **Create repository**.

### Шаг 2. Инициализация Git в папке с шаблонами
1. Откройте терминал (PowerShell или Git Bash) в вашей папке с шаблонами (`C:\Users\yamus\OneDrive\Рабочий стол\шаблон`).
2. Выполните следующие команды по очереди:

```bash
# 1. Инициализируем локальный репозиторий
git init

# 2. Добавляем все файлы папки в индекс Git
git add .

# 3. Делаем первый коммит
git commit -m "Initial commit of exam templates"

# 4. Переименовываем ветку в main
git branch -M main

# 5. Связываем локальный репозиторий с удаленным репозиторием GitHub
# (Замените ссылку на ссылку вашего созданного репозитория)
git remote add origin https://github.com/ВАШ_ЛОГИН/exam-templates.git

# 6. Отправляем файлы на GitHub (потребуется один раз войти в аккаунт на домашнем ПК)
git push -u origin main
```

## ЧАСТЬ 2: Развертывание шаблонов на экзамене (за 1 минуту)

### Вариант А. Если на экзаменационном компьютере УСТАНОВЛЕН Git
1. Запустите XAMPP (Apache и MySQL).
2. Откройте командную строку (cmd) или PowerShell.
3. Перейдите в папку `htdocs` сервера XAMPP:
   ```bash
   cd C:\xampp\htdocs
   ```
4. Склонируйте ваш репозиторий напрямую (ссылка берется с вашего GitHub):
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/exam-templates.git
   ```

---

### Вариант Б. Если на экзаменационном компьютере НЕ УСТАНОВЛЕН Git

Если консольная команда `git` недоступна, вы можете скачать проект двумя другими способами:

#### Способ 1. Через браузер (самый простой)
1. Откройте браузер на экзамене и перейдите на страницу вашего публичного репозитория: `https://github.com/ВАШ_ЛОГИН/exam-templates`
2. Нажмите на зелёную кнопку **Code** в правой верхней части страницы.
3. В выпадающем меню выберите **Download ZIP**.
4. Распакуйте скачанный архив прямо в папку `C:\xampp\htdocs\`. *(Папка будет называться `exam-templates-main`)*.

#### Способ 2. Через PowerShell командной строкой (если браузер ограничен)
Если вам нужно скачать проект именно консолью, на любом Windows-компьютере по умолчанию установлен PowerShell.
1. Откройте **PowerShell** на экзаменационном ПК.
2. Выполните скрипт из 3-х команд (скачивание, распаковка и удаление архива):

```powershell
# 1. Скачиваем ZIP-архив с GitHub в папку htdocs
Invoke-WebRequest -Uri "https://github.com/ВАШ_ЛОГИН/exam-templates/archive/refs/heads/main.zip" -OutFile "C:\xampp\htdocs\repo.zip"

# 2. Распаковываем ZIP-архив
Expand-Archive -Path "C:\xampp\htdocs\repo.zip" -DestinationPath "C:\xampp\htdocs"

# 3. Удаляем временный ZIP-архив
Remove-Item "C:\xampp\htdocs\repo.zip"
```
*(Проект будет распакован в папку `C:\xampp\htdocs\exam-templates-main`)*.

## ЧАСТЬ 3: Быстрый импорт базы данных через консоль (без phpMyAdmin)

Чтобы не тратить время на интерфейс phpMyAdmin, вы можете создать и заполнить базу данных одной командой в консоли за 1 секунду.

1. Откройте командную строку (cmd) или PowerShell.
2. Выполните команду импорта (она автоматически создаст базу `exam_project` и заполнит таблицы из `schema.sql`). 
*Примечание: Если вы скачали ZIP-архив, папка называется `exam-templates-main`*:

```bash
# Импорт файла schema.sql напрямую в MySQL
C:\xampp\mysql\bin\mysql -u root < C:\xampp\htdocs\exam-templates-main\schema.sql
```
*(Если папка без суффикса `-main`, то путь будет: `C:\xampp\htdocs\exam-templates\schema.sql`)*.
